# W04 Acceptance Checklist

- [x] لا يمكن لتسجيل الخروج استعادة رمز مدير محفوظ محليًا.
- [x] لا يُخزّن access token للموظفين في `localStorage`.

- [x] تدوير refresh token للموظفين يستهلك الرمز السابق ذريًا.
- [x] بدء وإيقاف الانتحال يمران بمسارات الخادم المسجلة في سجل التدقيق.
- [x] جلسة الانتحال لا تتحول بعد الانتهاء إلى جلسة عادية للحساب المنتحل.
- [ ] فحوص CI كاملة.
- [ ] مراجعة مستقلة قبل الدمج.
