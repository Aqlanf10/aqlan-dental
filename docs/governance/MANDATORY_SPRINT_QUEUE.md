# طابور السبرنتات الإلزامي — Mandatory Sprint Queue

**هذا الملف هو مصدر الحقيقة الوحيد لترتيب العمل على Aqlan Dental Pro.**
يلغي أي ترتيب سابق في ملفات الخطط التاريخية. الأدلة التفصيلية تبقى في
`docs/governance/SPEC_TO_CODE_TRACEABILITY.md` وملفات التدقيق والـPRs المرتبطة.

## القاعدة الإلزامية

1. قبل أي تطوير، اقرأ هذا الملف كاملًا.
2. أول عنصر بحالة `🔴 محجوب` أو `🟡 جاهز` أو `🔵 قيد التنفيذ` هو العمل الوحيد المسموح.
3. لا يجوز القفز لعنصر لاحق إلا لحادث إنتاج P0، تدقيق قراءة فقط، إكمال PR مفتوح، أو حل تعارض دمج.
4. كل PR تنفيذي يذكر رقم العنصر في العنوان، ويحدّث حالته عند تحقق معيار الخروج.
5. البنود المنجزة لا يعاد فتحها إلا بدليل ارتداد أو عطل إنتاجي جديد.

### ✅ CORE-FIN-LAB-ADJ — إعادة حساب العمولات وبنود التسوية (PR منفصل كما اشترط المالك)
- **ما نُفِّذ:** العمولات غير المدفوعة تُعاد حسبتها في مكانها عند تغيّر التكلفة الفعلية.
  العمولة **المدفوعة لا تُعدَّل ولا تُعاد كتابتها إطلاقًا** — يُنشأ بدلًا عنها بند تسوية
  مستقل موجب أو سالب (`DoctorCommissionAdjustment`) يحمل مرجع طلب المعمل والفاتورة
  والعمولة الأصلية، ويدخل التسوية القادمة للطبيب.
- **عدم التكرار مُقاس لا مُفترَض:** الفرق يُحسب مقابل بنود التسوية **المُنشأة فعلًا**
  لنفس البند، فإعادة التشغيل لا تُنشئ شيئًا، وتغيّرات التكلفة المتتالية تُغلق الفجوة
  مرة واحدة بالضبط (٣٥٬٠٠٠ ثم ٣٠٬٠٠٠ ⇐ ‎−٦٬٠٠٠‎ ثم ‎+٢٬٠٠٠‎ = ‎−٤٬٠٠٠‎ لا ‎−١٠٬٠٠٠‎).
- **قاعدتان كانتا ضمنيتين وكلتاهما كانت تُنقص الطبيب:**
  1. **`draft` ليس قرارًا** — لا يُخصم (التزام لم يُقطع) ولا يُصفَّر (إتلاف لتقدير الخدمة)؛
     يُترك البند كما هو. آمن لأن جدول الانتقالات لا يسمح بالعودة إلى `draft` إطلاقًا.
     **`cancelled` قرار** ⇐ يُحرَّر الخصم إلى صفر.
  2. **العملات لا تُجمع** — تكلفة المعمل تُحوَّل إلى عملة الفاتورة عبر الريال اليمني؛
     وعند غياب سعر صرف يربط العملتين **لا يُكتب شيء** ويُدرَج البند في قائمة الإصلاح
     الإداري بدل خصم رقم خاطئ بمقدار سعر الصرف كاملًا.
- **الرصيد:** بنود التسوية تدخل رصيد الطبيب فور إنشائها، فسقف الصرف في `RecordPayment`
  صار يعكسها. `Settled` **سجلّ** للدفعة التي حملت البند وليس بوابة حسابية — المجموع
  يشمل `Pending` و`Settled` معًا، فالدفعة الجزئية لا تُضيّع بندًا ولا تحسبه مرتين.
- **لم يُنفَّذ عمدًا:** لا استرداد تلقائي من الخزينة — البند السالب يخفض سقف الدفعة
  القادمة فقط؛ استرجاع مال مصروف قرار مالك لا مهمة خلفية. ولا اختراع روابط —
  الـbackfill يمسّ البنود التي تحمل `LabOrderId` فعلًا، والغامض يُبلَّغ عنه.
- **البنية:** جدول واحد جديد عبر startup DDL (إضافي بحت، لا جدول قائم لُمس، ولا migration
  تاريخية عُدِّلت).
- **الاختبارات:** ٢٥ اختبارًا خلفيًا + ٧ أمامية. **تحقق من عدم عقمها بالتخريب:** إزالة
  تجميد العمولة المدفوعة تُسقط ٧ اختبارات، وإزالة حد بنود التسوية السابقة تُسقط ٢.
- **البوابة:** ٢٧١٦/٢٧١٦ خلفي، ٥٤٣/٥٤٣ أمامي، tsc + lint + build نظيفة.
- **معيار الخروج:** مُحقَّق — لا تعديل صامت لأي عمولة مدفوعة، كل فرق ببند موثّق،
  والغامض إلى قائمة إصلاح إداري.
