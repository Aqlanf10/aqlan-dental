# CORE-PAT-022 — موثوقية جدول المرضى

## الأعطال المغلقة

1. **سباق نتائج البحث:** كان كل طلب بحث يستطيع تحديث الجدول عند اكتماله، حتى لو كان أقدم من الطلب الحالي؛ لذلك قد تستبدل نتيجة قديمة نتائج أحدث.
2. **الصفحات بعد الثالثة غير قابلة للوصول:** واجهة الترقيم كانت تنشئ أول ثلاثة أزرار فقط، بلا السابق أو التالي.
3. **فشل التصدير صامت:** أي فشل في طلب تصدير المرضى كان يُلتقط ويُهمَل بلا رسالة للمستخدم.

## الإصلاح

- إضافة رقم متسلسل لطلبات قائمة المرضى؛ لا يغيّر البيانات أو حالة التحميل إلا أحدث طلب.
- إظهار الصفحات القريبة من الصفحة الحالية، مع الصفحة الأولى والأخيرة وعلامات الحذف، وإضافة زري السابق والتالي.
- تعطيل زر التصدير أثناء التنفيذ لمنع الطلبات المكررة.
- عرض رسالة الخطأ العربية القادمة من الخادم عند فشل التصدير، ورسالة نجاح بعدد المرضى المصدّرين.
- إضافة اختبارات لمنطق الترقيم تشمل الصفحة الرابعة والصفحات الأخيرة والقيم الخارجة عن النطاق.
