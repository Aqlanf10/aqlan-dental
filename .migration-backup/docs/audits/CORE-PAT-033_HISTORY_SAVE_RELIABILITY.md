# CORE-PAT-033 — Patient history save reliability

## المشكلة

كان تبويبا التاريخ الطبي والسني يعرضان نسخة النموذج المحلي بعد الحفظ بدل البيانات التي اعتمدها الخادم. كما كانت رسائل التعارض والتحقق تختزل إلى رسالة عامة، وكانت إعادة المحاولة تمر مؤقتاً بحالة فارغة.

## المعالجة

- اعتماد استجابة الخادم كمصدر الحقيقة بعد الحفظ.
- عرض رسالة الخطأ المفصلة عبر `extractErrorMessage`.
- إعادة حالة التحميل في كل محاولة جديدة.
- إلغاء أثر الطلبات القديمة عند تغير المريض.
- إبقاء الخطأ منفصلاً عن حالة عدم وجود تاريخ مسجل.

## الاختبارات

تمت تغطية الحفظ الطبي والسني، ورسالة التعارض، وإعادة المحاولة بعد فشل التحميل.

## النطاق

لا توجد تغييرات في قاعدة البيانات أو المخطط.
