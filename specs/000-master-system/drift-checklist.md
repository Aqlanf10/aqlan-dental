# Master Drift Checklist

Use this before every PR.

- [ ] Did the request map to an existing spec?
- [ ] Did changed behavior update requirements/design/tasks?
- [ ] Did new route/module ownership update `module-map.md`?
- [ ] Did permissions change? If yes, update constraints and feature spec.
- [ ] Did finance behavior change? If yes, update `006-finance-stability`.
- [ ] Did ceph behavior change? If yes, update `005-cephalometry-workspace`.
- [ ] Did daily operations workflow change? If yes, update `002-daily-operations-workflow`.
- [ ] Did navigation/sidebar change? If yes, update `001-navigation-and-module-organization`.
- [ ] Did PDF/report identity change? If yes, update `009-reports-printing`.
- [ ] Did tests prove the requirement?
- [ ] Is anything marked `Needs runtime verification`?
- [ ] Are code and specs consistent?
