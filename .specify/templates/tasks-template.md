# Tasks Template

Tasks must be small, sequential, and scoped to existing module owners.

- Task ID:

- Can cheap model do it? Yes/No.

## Sequencing Rules

1. Update or confirm the spec first.
2. Inspect owners before editing.
3. Implement one task.
4. Run focused tests.
5. Update traceability.
6. Produce completion report.
