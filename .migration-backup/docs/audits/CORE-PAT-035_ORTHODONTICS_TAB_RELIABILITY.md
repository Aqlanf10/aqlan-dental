# CORE-PAT-035 — Orthodontics tab reliability

## المشكلة

كان تبويب التقويم يخفي فشل تحميل تفاصيل الحالات بصمت، ولا يعيد حالة التحميل بصورة صحيحة عند المحاولة الجديدة. كما كانت تفاصيل مريض سابق قابلة للوصول إلى الواجهة بعد تغير المريض.

## المعالجة

- إعادة ضبط الحالات والتفاصيل والأخطاء عند كل تحميل.
- إلغاء أثر الطلبات القديمة عند تغير المريض.
- تحميل تفاصيل الحالات بنتائج مستقلة عبر `Promise.allSettled`.
- إبقاء قائمة الحالات ظاهرة عند فشل بعض التفاصيل.
- إظهار تحذير جزئي وحالة فشل خاصة بالحالة المتأثرة.
- توفير إعادة محاولة كاملة دون عرض حالة فارغة كاذبة.

## الاختبارات

تمت تغطية فشل القائمة الأساسي، وفشل بعض تفاصيل الحالات، والتعافي بعد إعادة المحاولة.

## النطاق

تبويب التقويم داخل ملف المريض فقط، دون تغييرات في قاعدة البيانات أو مخططها.
