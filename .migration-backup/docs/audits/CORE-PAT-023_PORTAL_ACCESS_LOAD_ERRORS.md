# CORE-PAT-023 — صدق حالة حساب بوابة المريض

## العطل

كان `PortalAccessTab` يلتقط جميع أخطاء جلب بيانات الحساب، سواء كانت 401 أو 403 أو 500 أو انقطاع شبكة، ثم يضع `creds = null`. بعد ذلك تعرض الواجهة «لا يوجد حساب بوابة لهذا المريض» وتتيح إنشاء حساب، رغم أن حالة الحساب الحقيقية لم تُحمّل أصلًا.

## الإصلاح

- الاستجابة الناجحة التي تحمل `hasPortalAccount: false` وحدها تعرض حالة «لا يوجد حساب».
- أخطاء الشبكة والخادم والصلاحيات تظهر كحالة خطأ عربية مستقلة مع زر إعادة محاولة.
- لا تظهر إجراءات إنشاء الحساب أو إعادة تعيين كلمة المرور عند فشل تحميل الحالة.
- توحيد رسائل أخطاء إنشاء الحساب وإعادة التعيين مع `extractErrorMessage`.

## اختبارات منع الرجوع

1. فشل 503 يعرض رسالة الخادم ولا يعرض حالة «لا يوجد حساب» الكاذبة.
2. إعادة المحاولة تنفذ طلبًا جديدًا ثم تعرض الحالة الحقيقية عند النجاح.
3. الاستجابة الناجحة `hasPortalAccount: false` تبقى حالة فارغة صحيحة بلا رسالة خطأ.
