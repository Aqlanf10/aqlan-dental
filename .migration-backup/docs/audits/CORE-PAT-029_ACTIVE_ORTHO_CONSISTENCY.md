# CORE-PAT-029 — تعريف موحد للحالة التقويمية النشطة

## العطل

كانت الحالة التقويمية «النشطة» تُحسب بأكثر من تعريف:

- ملخص المريض ولوحة القيادة استخدما `Status == Active`.
- ملخص الرحلة اليومية استخدم `IsActive` فقط، وهو علم الحذف المنطقي وليس دورة الحالة السريرية.
- نظرة المريض جلبت أحدث خمس حالات بلا فلتر ثم بحثت محليًا عن Active، لذلك قد تختفي حالة نشطة أقدم خلف حالات مكتملة أحدث.
- إنشاء الحالة التقويمية الجراحية عرض كل حالات التقويم، بما فيها المكتملة والملغاة.

## الإصلاح

- إضافة `ActiveCases()` كتعريف مركزي: `IsActive && Status == OrthoCaseStatus.Active`.
- استخدام التعريف في ملخص المريض، لوحة القيادة، ملخص الرحلة اليومية، والتحميل المسبق للتشغيل اليومي.
- إضافة `patientActiveOrthoCasesUrl()` في الواجهة لإرسال `status=active` وpagination محددة صراحةً.
- استخدام الرابط الموحد في نظرة المريض وفي قائمة الحالات المتاحة للربط الجراحي.

## اختبارات منع الرجوع

- حالة Active وغير محذوفة وحدها تمر؛ Completed أو soft-deleted لا تمر.
- عقد مصدر يثبت استخدام `ActiveCases()` في المستهلكين الخلفيين الرئيسيين.
- اختبار رابط الواجهة يثبت وجود `status=active` وحدود الصفحة.
