# CORE-PAT-030 — Ortho-surgical load errors

## المشكلة

كان تبويب الحالات التقويمية الجراحية يلتقط أخطاء تحميل الحالات بصمت. عند فشل الخادم أو الشبكة، كانت الواجهة تعرض حالة فارغة مضللة وكأن المريض لا يملك حالات جراحية.

## المعالجة

- استخدام `Promise.allSettled` لفصل نتيجة تحميل الحالات الجراحية عن نتيجة تحميل حالات التقويم النشطة المرشحة.
- إظهار خطأ كامل وقابل لإعادة المحاولة عند فشل قائمة الحالات الجراحية، دون تحويل الخطأ إلى حالة فارغة.
- الحفاظ على الحالات الجراحية الناجحة عند فشل طلب أهلية الإنشاء فقط، مع تحذير جزئي واضح.
- منع إنشاء حالة جديدة حتى ينجح التحقق من وجود حالة تقويمية نشطة.
- توحيد رسائل أخطاء الإنشاء والتحميل عبر `extractErrorMessage`.

## الاختبارات

يغطي الاختبار المضاف:

1. فشل القائمة الأساسية وعدم إظهار حالة فارغة كاذبة.
2. فشل تحميل المرشحين مع بقاء الحالة الفارغة الحقيقية وتحذير المستخدم.
3. إعادة المحاولة محليًا وإعادة تشغيل الطلبين دون إعادة تحميل الصفحة.

## النطاق

لا توجد تغييرات في قاعدة البيانات أو المخطط أو صلاحيات النظام.
