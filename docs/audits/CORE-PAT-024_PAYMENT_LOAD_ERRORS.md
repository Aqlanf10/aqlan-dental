# CORE-PAT-024 — صدق تحميل مدفوعات المريض

## العطل

كان `PaymentsTab` يضع `.catch(() => [])` داخل طلبي المدفوعات والعقود. لذلك كانت الأخطاء تتحول إلى مصفوفات فارغة قبل وصولها إلى معالج الخطأ، وتعرض الواجهة «إجمالي المدفوعات 0» و«لا توجد مدفوعات» عند تعطل الخادم.

## الإصلاح

- استخدام `Promise.allSettled` للفصل بين فشل المدفوعات وفشل العقود.
- فشل طلب المدفوعات يعرض رسالة عربية وإعادة محاولة، ولا يعرض بطاقات الإجمالي أو العدد.
- الاستجابة الفارغة الناجحة وحدها تسمح بعرض الصفر كقيمة صحيحة.
- فشل العقود وحده لا يمحو المدفوعات الناجحة؛ تظهر رسالة منفصلة ويُعطّل ربط الدفعة بالعقد مؤقتًا.

## اختبارات منع الرجوع

1. فشل 503 في المدفوعات لا يعرض إجماليًا صفريًا ولا حالة فارغة كاذبة.
2. الاستجابة الناجحة الفارغة تعرض «لا توجد مدفوعات» وصفرًا صحيحًا.
