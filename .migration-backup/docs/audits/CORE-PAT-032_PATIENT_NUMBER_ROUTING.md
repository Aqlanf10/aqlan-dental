# CORE-PAT-032 — Patient number routing

## المشكلة

كانت صفحة ملف المريض ترسل طلبات تعتمد على GUID حتى عندما يحتوي الرابط رقم الملف، وكانت تعرض أخطاء الخدمة كحالة عدم وجود مريض.

## المعالجة

- تحويل رقم الملف إلى GUID قبل تحميل بيانات الملف.
- عدم إرسال طلبات الملف والملخص والحالات إلا بعد توفر GUID صحيح.
- تمييز استجابة 404 عن أخطاء الخدمة والاتصال.
- توفير إعادة محاولة محلية.
- منع الطلبات القديمة من تحديث الصفحة بعد تغير المعرف.

## الاختبارات

تمت تغطية التحويل الناجح، وحالة 404، وفشل الخدمة، ومسار GUID الطبيعي.

## النطاق

صفحة ملف المريض واختباراتها فقط، دون تغييرات في قاعدة البيانات.
