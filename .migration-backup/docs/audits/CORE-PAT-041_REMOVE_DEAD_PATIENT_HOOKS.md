# CORE-PAT-041 — Remove dead patient hooks facade

## المشكلة

كان الملف `frontend/src/hooks/usePatients.ts` يحتوي 203 أسطر من hooks موازية لتدفقات المرضى الفعلية، لكنه لا يملك أي استيراد داخل التطبيق. أبقاؤه يخلق مصدرًا ثانيًا قديمًا لمسارات المرضى والبوابة والأرشفة ويزيد احتمال استخدامه لاحقًا دون اختبارات واجهات الوحدة الحالية.

## المعالجة

- البحث على مستوى المستودع عن اسم الملف ومسار الاستيراد وجميع الصادرات.
- التحقق من عدم وجود أي مستدعٍ فعلي.
- حذف الواجهة المهجورة بدل صيانتها بالتوازي مع مكونات المرضى المعتمدة.

## الأمان

لا تتغير أي واجهة مستخدم أو API أو قاعدة بيانات. فحوصات TypeScript والبناء ستكشف أي استيراد غير ظاهر.

## ملاحظة النشر

تجاوز مشروع Vercel حد عمليات النشر اليومية؛ يعتمد قبول التغيير على CI الكامل إلى أن تتجدد الحصة الخارجية.
