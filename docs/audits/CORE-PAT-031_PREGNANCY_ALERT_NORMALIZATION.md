# CORE-PAT-031 — Pregnancy alert normalization

## المشكلة

حقل الحمل في التاريخ الطبي ثلاثي القيم: `Yes` و`No` و`N/A`. كان ملخص المريض يستخدم قائمة استثناءات محدودة، ولذلك كان يصنف `N/A` (لا ينطبق) والقيم القديمة غير المعروفة كتنبيه حمل، ما ينتج تحذيراً سريرياً خاطئاً.

## المعالجة

- اعتماد قائمة إيجابية صريحة للقيم التي تعني وجود حمل فعلاً.
- عدم إنشاء تنبيه حمل للقيم `No` و`N/A` والقيم الفارغة أو غير المعروفة.
- توحيد نص التنبيه إلى `حمل`.
- الحفاظ على تنبيهات الحساسية والأمراض المزمنة والأدوية واضطرابات النزف ومشكلات المفصل دون تغيير.

## الاختبارات

تغطي الاختبارات:

1. القيم السلبية والمحايدة، بما فيها `N/A` و`لا ينطبق`.
2. القيم الإيجابية الإنجليزية والعربية.
3. بقاء بقية التنبيهات الطبية مع عدم إضافة حمل كاذب.

## النطاق

لا توجد تغييرات في قاعدة البيانات أو المخطط أو نموذج التخزين.
