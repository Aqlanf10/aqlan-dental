## Honest current result

No adjudicated reference dataset was available in this PR. Therefore Aqlan MRE, SDR, per-landmark error, derived-measurement error, subgroup performance, repeatability, and WebCeph paired error are **not measured**. Build and unit-test results must not populate this report.

The existing `/ceph/ai-quality` metrics are doctor-correction telemetry from clinical use. They are not interchangeable with a locked gold-standard benchmark because correction/no-correction is affected by reviewer behavior, case mix, missing points, and model exposure.
