# بوابات الجودة

لا تعتبر أي وحدة منتهية قبل تحقق ما يلي:

## الوظيفة

- المسار الأساسي يعمل من البداية للنهاية ضد API الحقيقي.
- حالات التحميل والفراغ والنجاح والخطأ وانتهاء الجلسة واضحة.
- الصلاحيات تمنع إظهار وتنفيذ العملية غير المسموحة.
- لا توجد أزرار أو روابط لا تعمل.

## اللغة والتصميم

- كل نص للمستخدم موجود بالعربية والإنجليزية.
- التبديل الفوري لا يكسر الشاشة أو المدخلات.
- RTL وLTR صحيحان في العناوين والصفوف والنماذج.
- الهوية والألوان والمسافات من نظام التصميم المركزي.
- النصوص الطويلة تعمل على شاشة هاتف ضيقة مع تكبير الخط.

## الأمان والاستقرار

- الأسرار والجلسات في SecureStore، ولا تطبع التوكنات في السجل.
- مدخلات الشبكة تتحقق وقت التشغيل.
- لا إعادة تلقائية لطلبات التعديل.
- الخطأ المحلي لا يغلق التطبيق بالكامل.

## التحقق الآلي

```bash
npm run test:i18n
npm run typecheck
npm run export:android
npm run export:ios
```

## التحقق على الجهاز

- تثبيت APK جديد تثبيتًا نظيفًا.
- الدخول والخروج واستعادة الجلسة بعد إغلاق التطبيق.
- تبديل اللغة في الدخول ومساحة العمل.
- تجربة انقطاع الإنترنت وكلمة مرور خاطئة وانتهاء الجلسة.
- ضغط متكرر وسريع على الإجراءات الحساسة للتأكد من منع التكرار.
