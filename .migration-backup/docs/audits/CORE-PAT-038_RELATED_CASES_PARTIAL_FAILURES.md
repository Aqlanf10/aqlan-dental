# CORE-PAT-038 — Related-case partial failures

## المشكلة

كانت صفحة معلومات المريض تستخدم رسالة خطأ مشتركة لحالات التقويم والجراحة. فشل أحد الطلبين كان يطمس نجاح الآخر، وكانت إعادة المحاولة تعيد تحميل ملخص المريض والمالية بلا حاجة.

## المعالجة

- فصل أخطاء حالات التقويم عن الحالات الجراحية.
- تحميل القائمتين بنتائج مستقلة عبر `Promise.allSettled`.
- الحفاظ على نتيجة القائمة الناجحة عند فشل الأخرى.
- تسمية الجزء المتعذر تحميله بوضوح.
- إضافة حالة تحميل صريحة للحالات المرتبطة.
- استخدام مفتاح إعادة محاولة مستقل لا يعيد تحميل الملف أو الملخص أو المالية.
- تجاهل نتائج الطلبات القديمة بعد تغير المريض.

## الاختبارات

أضيف عقد اختبار يحمي الفصل بين الطلبين، ورسائل الفشل الجزئي، وحالة التحميل، ومفتاح إعادة المحاولة المستقل.

## النطاق

لا توجد تغييرات في قاعدة البيانات أو مخططها.

## ملاحظة النشر

تجاوز مشروع Vercel حد عمليات النشر اليومية؛ يعتمد قبول التغيير على CI الكامل إلى أن تتجدد الحصة الخارجية.
