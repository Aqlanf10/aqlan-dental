# CORE-PAT-034 — Finance tab retry reliability

## المشكلة

كان خطأ كشف الحساب يبقى عالقاً بعد نجاح تحميل لاحق، ولم تكن حالة التحميل تعود عند تغير مفتاح التحديث. كما كان فشل الفواتير الجزئي يعرض رسالة بلا إعادة محاولة.

## المعالجة

- تحميل كشف الحساب والفواتير بنتيجتين مستقلتين.
- مسح الأخطاء وإعادة حالة التحميل في كل تحديث.
- إظهار خطأ كامل قابل لإعادة المحاولة عند فشل كشف الحساب.
- إبقاء كشف الحساب ظاهراً عند فشل الفواتير فقط.
- إضافة إعادة محاولة للفواتير ومنع الطلبات القديمة من تحديث الصفحة.

## الاختبارات

تمت تغطية الفشل الكامل، والفشل الجزئي، ونجاح التحديث بعد خطأ سابق.

## النطاق

تبويب المالية داخل ملف المريض فقط، دون تغييرات في قاعدة البيانات.
